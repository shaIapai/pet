# Конвертер валют

Простой скрипт для конвертации денег между рублём, юанем, долларом, евро и тенге. Работает прямо в консоли — вводишь сумму и валюты, получаешь результат.

## Возможности

- Конвертация между 5 валютами: RUB, CNY, USD, EUR, KZT
- Понимает не только коды валют, но и обычные слова: «рубль», «баксы», «евро», «тенге» и т.д.
- Не важен регистр — можно писать USD, usd или Usd
- Проверяет ввод и просит повторить, если ошибся с суммой или валютой

## Как запустить

```bash
python конвертер.py
```

## Как пользоваться

Скрипт спросит по порядку:

1. Сумму для конвертации
2. Валюту, из которой конвертируем
3. Валюту, в которую конвертируем

Пример:

```
Введите сумму для конвертации: 100
Введите валюту, из которой конвертировать (например, USD, EUR, CNY, RUB): доллар
Введите валюту, в которую конвертировать (например, USD, EUR, CNY, RUB): rub
100.00 USD равно 7120.90 RUB
```

Можно писать как код валюты (USD), так и синоним (доллар, бакс, dollar) — скрипт сам разберётся.

## Поддерживаемые валюты и синонимы

| Валюта | Код | Синонимы |
|---|---|---|
| Рубль | RUB | рубль, руб, rub |
| Юань | CNY | юань, yuan, cny |
| Доллар | USD | доллар, бакс, dollar, usd |
| Евро | EUR | евро, еврик, euro, eur |
| Тенге | KZT | тенге, тенг, тэнге, тенгэ |

## Важно

Курсы обмена не обновляются автоматически — это фиксированные значения на момент написания скрипта. Для реальных операций стоит свериться с актуальным курсом.

## Требования

Python 3, никаких сторонних библиотек не нужно.
